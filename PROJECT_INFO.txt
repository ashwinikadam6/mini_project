1. PROJECT OVERVIEW
------------------
SafeRoute AI is a comprehensive road safety and risk management platform designed 
to minimize traffic accidents using Artificial Intelligence and real-time data. 
The system predicts road risk levels, provides safety-optimized navigation, and 
allows for real-time crowdsourcing of road hazards.

8. METHODOLOGY
--------------
The development of SafeRoute AI followed a structured data-to-deployment pipeline:

A. DATA COLLECTION & SYNTHESIS
   - Generated a synthetic dataset of 1,000 accident records based on real-world 
     Nagpur geography (Sitabuldi, Wardha Road, Sadar, etc.).
   - Features captured: Time of day, weather condition, road type, traffic 
     density, and historical accident counts.

B. MACHINE LEARNING MODEL
   - Algorithm: Random Forest Classifier.
   - Configuration: 100 estimators, max depth of 10, balanced class weights.
   - Training: 80-20 train-test split with stratified sampling.
   - Metrics: ~91.4% accuracy with high precision for 'High Risk' detection.
   - Feature Importance: Traffic density and Time of Day (Night/Peak) were 
     identified as the strongest predictors of risk.

9. ROUTING LOGIC (THE A* ALGORITHM)
----------------------------------
The core of the safety-first navigation is a custom-weighted A* algorithm.

A. WEIGHT FORMULA
   For every road segment (edge) in the OpenStreetMap network:
   Weight = Physical Length (m) + (Risk Score * Risk Penalty)

   - Risk Penalty: Tunable constant (default 500m).
   - Effect: A highly dangerous road (risk=1.0) is treated as being 500m 
     longer than it actually is, forcing the router to prefer safer detours.

B. RISK SCORE CONTRIBUTORS
   - Highway Type (20%): Motorways/Trunks ranked as higher risk.
   - Speed Limit (20%): Higher speed roads penalized for crash severity.
   - Lighting (15%): Unlit roads after dark receive a significant penalty.
   - Surface (15%): Rough/unpaved surfaces increase the risk score.
   - Junctions (10%): Complex intersections add minor risk weight.
   - Blackspots (20%): Proximity to historical accidents using Haversine 
     distance with a 250m decay radius.

10. SYSTEM IMPLEMENTATION
-------------------------
A. BACKEND (FLASK)
   - REST Endpoints: Used for authentication, prediction, and routing.
   - Proxy Layer: Fetches live data from OpenWeatherMap and TomTom to prevent 
     exposing API keys to the frontend.
   - JWT Auth: Ensures only registered users can report hazards.

B. REAL-TIME (WEBSOCKETS)
   - Event: 'new_hazard'
   - Mechanism: When a user reports a pothole or accident, the server 
     broadcasts the event instantly to all connected clients.
   - Benefit: Zero-latency awareness for drivers on the road.

C. FRONTEND (REACT)
   - Component-based architecture for Map, Dashboard, and Stats.
   - Leaflet Integration: Custom icons for hazards and color-coded route 
     lines (Safe = Green, Shortest = Red).

12. USER MANUAL / HOW TO RUN
----------------------------
1. BACKEND SETUP:
   - Navigate to the project root.
   - Install dependencies: `pip install -r requirements.txt` (or manually 
     install flask, scikit-learn, osmnx, etc.).
   - Set up .env file with your API keys (OpenWeather, TomTom).
   - Run the ML model: `python ml_model.py` (generates model.pkl).
   - Start the server: `python app.py`.

2. FRONTEND SETUP:
   - Navigate to `/frontend`.
   - Install packages: `npm install`.
   - Start dev server: `npm run dev`.
   - Open browser at `http://localhost:5173`.

3. USAGE:
   - Login/Register to access the full features.
   - Search for a destination to compute the safest route.
   - Use the "Report" button to flag road hazards in real-time.
